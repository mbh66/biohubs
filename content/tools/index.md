Software and services that support the work of building a BioConomy. Each tool sits under the layer of the [[glossary/biostack|BioStack]] where its use is most natural.

## Organized by BioStack layer

- [[tools/bioplace/index|BioPlace Tools]]. Software and services for the parcel-scale human-land layer.
- BioHub Tools (folder to be added when the first tool arrives).
- BioRegion Tools (folder to be added when the first tool arrives).
- BioConomy Tools (folder to be added when the first tool arrives).

## How the folder is organized

One page per tool. Each entry names what the tool does, who builds it, its pricing posture, its technology stack where relevant, and the specific BioConomy work it supports. Tools that serve more than one layer are cross-linked from the folders they belong in.
