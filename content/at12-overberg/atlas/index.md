# BioRegion Atlas

The Atlas breaks the BioRegion into nine ecological profiles, each a standalone page with structured frontmatter for AI agent parsing. To be populated through the BioRegion Establishment Template Prompt 2.

## Profiles

1. **[Hydrology](/atlas/hydrology)** — The Riviersonderend catchment, Theewaterskloof Dam, below-dam corridor, Western Cape Water Supply System
2. **[Geology and Soils](/atlas/geology-soils)** — Substrate condition, soil types, retention capacity
3. **[Biodiversity](/atlas/biodiversity)** — Cape Floristic Region, fynbos biome, renosterveld, Cape Mountain Leopard corridor
4. **[Climate](/atlas/climate)** — Precipitation regime, orographic rainfall, seasonal patterns, climate projections
5. **[Cultural Heritage](/atlas/cultural-heritage)** — Genadendal (1738), mission settlements, Khoi-San heritage, agricultural history
6. **[Jurisdictional](/atlas/jurisdictional)** — Four local municipalities, district municipality, CMA, CapeNature, water user associations
7. **[Economic](/atlas/economic)** — Agriculture, tourism, fishing, land use, employment patterns
8. **[Invasive Species](/atlas/invasive-species)** — Alien clearing status, species inventory, yield impact modelling
9. **[Restoration Baseline](/atlas/restoration-baseline)** — Current condition, restoration targets, monitoring methodology alignment

Each profile page will carry structured YAML frontmatter for peer BioHub agent interoperability.
